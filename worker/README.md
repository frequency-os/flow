# Flow AI Worker

Проксі між застосунком і Anthropic. Живе в Cloudflare Workers.

**Навіщо він взагалі.** Ключ від Anthropic не можна класти в застосунок — його
видно кожному, хто відкриє код сторінки. Тому застосунок звертається до воркера,
а ключ лежить тут, на сервері.

## Куди це ставити

1. **dash.cloudflare.com** → **Workers & Pages**
2. Відкрий свій воркер (той, чия адреса вказана в застосунку:
   Ще → Всі налаштування → AI-проксі)
3. **Edit code** → виділити все → вставити вміст `flow-ai-worker.js`
4. **Deploy**

## Змінні оточення

У воркері: **Settings** → **Variables and Secrets**

| Змінна | Обовʼязкова | Навіщо |
|---|---|---|
| `ANTHROPIC_API_KEY` | так | ключ від Anthropic |
| `ELEVENLABS_KEY` | для голосу | нейронний голос, див. нижче |
| `ELEVENLABS_VOICE_ID` | ні | якщо не задано — береться перший в акаунті |
| `AZURE_SPEECH_KEY` | запасний варіант | якщо ElevenLabs не підійшов |
| `AZURE_SPEECH_REGION` | запасний варіант | напр. `westeurope` |
| `FLOW_SECRET` | ні | пароль до воркера, див. нижче |

І одна прив'язка: **Settings** → **Bindings** → **Workers AI** з іменем `AI`
(потрібна для розпізнавання голосу).

## Про `FLOW_SECRET`

Адреса воркера відкрита всьому інтернету, а за виклики платиш ти. Хто завгодно,
знайшовши адресу, може витрачати твої кошти.

Якщо задати `FLOW_SECRET`, воркер вимагатиме цей пароль у заголовку `x-flow-key`.
**Але застосунок його поки не надсилає** — тож вмикати треба разом із правкою в
застосунку, інакше AI перестане працювати.

Поки змінна не задана, воркер працює як раніше, без пароля.

## Нейронний голос

Раніше тут стояв реверс приватного ендпоінта Microsoft (Edge Read Aloud).
**Він не працює з Cloudflare.** Перевірено прямо: з домашньої адреси приходить
15 КБ звуку, з воркера — нуль, при тих самих токені й голосі. Microsoft
дозволяє домашні адреси і мовчки відмовляє дата-центрам: приймає зʼєднання,
відповідає `turn.start / response / turn.end` і не дає жодного кадру.

Тепер голос іде через **офіційний Azure Speech** — ті самі голоси
`uk-UA-OstapNeural` і `uk-UA-PolinaNeural`, тільки легально й надійно.

### ElevenLabs — головний варіант

Обраний першим, бо **картка при реєстрації не потрібна**. Українська є.

1. **elevenlabs.io** → Sign up (пошта, без картки)
2. Кабінет → профіль → **API Keys** → створити ключ
3. У воркері: Settings → Variables and Secrets → `ELEVENLABS_KEY`

**Безкоштовно: 10 000 символів на місяць.** Це приблизно 100–150 коротких
реплік помічника. На довгі тексти замало — але саме короткі й чути найчастіше.

Коли ліміт вичерпано, ElevenLabs віддає помилку, а застосунок сам переходить
на системний голос. Озвучка не зникає, лише спрощується.

Голос можна обрати свій: скопіювати `Voice ID` у кабінеті і покласти в
`ELEVENLABS_VOICE_ID`. Якщо не задавати — воркер візьме перший доступний.

### Azure — запасний варіант

Дає 500 000 символів на місяць замість 10 000, але вимагає картку і часто
блокує реєстрацію.

1. **portal.azure.com** → Create a resource → **Speech** → рівень **F0**
2. Ресурс → **Keys and Endpoint** → `KEY 1` і `Location/Region`
3. У воркері: `AZURE_SPEECH_KEY` і `AZURE_SPEECH_REGION`

Якщо задані обидва ключі, використовується ElevenLabs.

Поки ключа немає, `/tts` чесно повертає 503, і застосунок сам переходить на
системний голос («Леся» на macOS/iOS). Нічого не ламається — просто звучить
простіше.

## Що змінилось 30.08.2026

| | Було | Стало |
|---|---|---|
| Стеля відповіді | 4096 завжди | до 64000 зі стрімом |
| Думання моделі | немає | адаптивне, де модель це вміє |
| Кешування підказки | немає | системна підказка + інструменти |
| Модель Sonnet | 4.6 ($3/$15) | 5 ($2/$10) — новіша й дешевша |
| Помилки | голе «HTTP 400» | текст від Anthropic |
| Таймаут | немає | 180 с, потім зрозуміла відповідь |
| Захист адреси | немає | `FLOW_SECRET` (необовʼязково) |
| Голос | реверс Edge (не працює з Cloudflare) | офіційний Azure Speech |

### Чому саме ці зміни

**Стеля 4096** обривала довгі плани й розбори на півслові. Тепер велика стеля
дозволена лише зі стрімом — без нього запит не встиг би за таймаут.

**Думання** — головне. Модель сама вирішує, скільки міркувати. Це різниця між
«склав список» і «побачив закономірність». Безпечно, бо застосунок повертає
блоки думання назад у розмову (`conv.push` з усім `content`).

**Кешування.** Системна підказка й описи 14 інструментів однакові з ходу в хід,
але летіли в модель щоразу заново. В агентному циклі буває 3–5 ходів — тепер
повторне читання коштує близько десятої частини.

**Sonnet 4.6 → 5.** Підміна відбувається у воркері, застосунок правити не треба.
Новіша модель, і водночас дешевша.

## Моделі

Застосунок обирає модель сам (`aiPickModel`): простий запит — Haiku,
складний («розплануй», «проаналізуй», довгий текст) — Sonnet.

| Модель | Вхід / вихід за млн | Думає |
|---|---|---|
| `claude-haiku-4-5` | $1 / $5 | ні |
| `claude-sonnet-5` | $2 / $10 | так |
| `claude-opus-5` | $5 / $25 | так |

`claude-opus-5` дозволений, але застосунок його поки не просить. Якщо захочеш
найрозумнішу модель на важких задачах — це правка в `aiPickModel`
(`src/scripts/core/12-ai-agent.js`), скажи.

## Перевірити, що працює

```bash
curl -s -X POST <адреса-воркера> \
  -H 'content-type: application/json' \
  -d '{"model":"claude-haiku-4-5","max_tokens":64,"messages":[{"role":"user","content":"скажи: працює"}]}'
```

Має повернутись JSON з відповіддю. Якщо помилка — тепер у ній буде причина,
а не просто код.
