# Flow AI Worker

Проксі між застосунком і Anthropic. Живе в Cloudflare Workers.

**Навіщо він взагалі.** Ключ від Anthropic не можна класти в застосунок — його
видно кожному, хто відкриє код сторінки. Тому застосунок звертається до воркера,
а ключ лежить тут, на сервері.

## Куди це ставити

0. **Спершу резерв.** Відкрий воркер у Cloudflare → **Edit code**, виділи все,
   скопіюй і збережи в окремий файл. Код у Cloudflare і код тут колись
   розходились: там могли бути `/translate` і `/upload-photo`, яких тут нема.
   Якщо щось піде не так, вставиш старий назад.
1. **dash.cloudflare.com** → **Workers & Pages**
2. Відкрий свій воркер (той, чия адреса вказана в застосунку:
   Ще → Всі налаштування → AI-проксі)
3. **Edit code** → виділити все → вставити вміст `flow-ai-worker.js`
4. **Deploy**

**Порядок важливий: спершу воркер, потім застосунок.** Новий застосунок шле
заголовок `Authorization`. Старий воркер його не знає, і браузер відмовить.
Застосунок це переживе (повторить запит без заголовка), але чисто буде тоді,
коли воркер оновлено першим.

Новий воркер без жодних нових змінних працює і зі старим застосунком: сайт,
десктоп і файл з диска пропускаються, вхід не вимагається.

## Змінні оточення

У воркері: **Settings** → **Variables and Secrets**. Ключі — тип **Secret**,
решта — **Text**.

| Змінна | Обовʼязкова | Навіщо |
|---|---|---|
| `ANTHROPIC_API_KEY` | так | ключ від Anthropic |
| `ELEVENLABS_KEY` | для голосу | нейронний голос, див. нижче |
| `ELEVENLABS_VOICE_ID` | ні | якщо не задано — береться вбудований |
| `AZURE_SPEECH_KEY` | запасний варіант | якщо ElevenLabs не підійшов |
| `AZURE_SPEECH_REGION` | запасний варіант | напр. `westeurope` |
| `ALLOWED_ORIGINS` | ні | хто може кликати воркер, див. «Замок» |
| `ALLOW_OPUS` | ні | `1` — дозволити найдорожчу модель Opus |
| `RATE_PER_MIN` | ні | скільки запитів на хвилину з однієї IP (за замовч. 30) |
| `SUPABASE_URL` | ні | вмикає вимогу входу, див. «Замок» |
| `SUPABASE_ANON` | ні | публічний anon-ключ Supabase (разом із `SUPABASE_URL`) |
| `ALLOWED_USERS` | ні | пошти або id через кому — пускати лише цих людей |
| `FLOW_SECRET` | ні | старий пароль; справжнім захистом не є, не задавай |

І одна прив'язка: **Settings** → **Bindings** → **Workers AI** з іменем `AI`
(потрібна для розпізнавання голосу).

## Замок

Адреса воркера лежить у публічному репо, а за виклики платиш ти. Тому воркер
тепер зачинений у кілька шарів.

**1. Лише свої сторінки (Origin).** За замовчуванням пускає:

- `https://frequency-os.github.io` — сайт
- `null` — збірка, відкрита з диска (`file://`)
- `app://frequency` — десктоп
- `capacitor://localhost` — iOS-обгортка
- `http://localhost:*`, `http://127.0.0.1:*` — локальна перевірка
- `none` — запити зовсім без Origin

Чужий сайт отримує 403. Запити без Origin пропускаються навмисно: сторінка,
відкрита з диска в Electron, Origin не шле взагалі (перевірено 25.09), а
закривати їх — ризик зламати живий застосунок заради нуля користі.
Свій список можна задати в `ALLOWED_ORIGINS` через кому: `:*` у кінці —
будь-який порт, `none` — пускати запити без Origin, `*` — пускати всіх.

Чесно: скрипт легко підробляє Origin або просто його не шле. Це замок від
чужих **сайтів**. Від скриптів захищають наступні шари.

**2. Лише дешеві моделі.** Haiku і Sonnet. Opus ($25 за млн вихідних токенів)
закритий, доки не задано `ALLOW_OPUS=1`. Відповідь — не більше 8192 токенів
(раніше зі стрімом дозволялось 64000, це ~$1.6 за один запит Opus).

**3. Ліміт частоти.** 30 запитів на хвилину з однієї IP-адреси: окремо на
розмову й окремо на голос. Один хід агента — до 6 запитів, тож людині це не
заважає. Далі — відповідь 429 «спробуй за N с». Лічильник живе в пам'яті
воркера, а Cloudflare тримає кілька його копій, тож ліміт приблизний. Але
цикл «тисяча запитів підряд» він зупиняє.

**4. Вхід у застосунок (вмикається окремо).** Задай `SUPABASE_URL`
(`https://<проєкт>.supabase.co`) і `SUPABASE_ANON` (публічний anon-ключ, той
самий, що вже є в застосунку). Тоді воркер пускає лише тих, хто увійшов у
Frequency через Google: застосунок шле токен сесії, воркер питає Supabase,
чи він живий. Хто не увійшов, отримає 401 і текст «увійди в застосунок».

Вмикати це варто лише тоді, коли новий застосунок уже викладено, бо саме він
шле токен. Важливо: увійти через Google може будь-хто. Щоб пустити лише себе,
додай `ALLOWED_USERS` зі своєю поштою.

**Про `FLOW_SECRET`.** Лишився для сумісності. Застосунок його не шле і слати
не буде: пароль у публічному коді — не пароль. Якщо його задати, AI у
застосунку перестане працювати.

**Страховка поза кодом:** у консолі Anthropic (console.anthropic.com → Limits)
можна поставити місячну стелю витрат. Навіть якщо все інше підведе, більше
за неї не спишуть.

## Нейронний голос

Раніше тут стояв реверс приватного ендпоінта Microsoft (Edge Read Aloud).
**Він не працює з Cloudflare.** Перевірено прямо: з домашньої адреси приходить
15 КБ звуку, з воркера — нуль, при тих самих токені й голосі. Microsoft
дозволяє домашні адреси і мовчки відмовляє дата-центрам: приймає зʼєднання,
відповідає `turn.start / response / turn.end` і не дає жодного кадру.

Тепер голос іде через **офіційний Azure Speech** — ті самі голоси
`uk-UA-OstapNeural` і `uk-UA-PolinaNeural`, тільки легально й надійно.

### ElevenLabs — головний варіант

Обраний першим, бо **картка при реєстрації не потрібна**. Українська є.

1. **elevenlabs.io** → Sign up (пошта, без картки)
2. Кабінет → профіль → **API Keys** → створити ключ
3. У воркері: Settings → Variables and Secrets → `ELEVENLABS_KEY`

**Безкоштовно: 10 000 символів на місяць.** Це приблизно 100–150 коротких
реплік помічника. На довгі тексти замало — але саме короткі й чути найчастіше.

Коли ліміт вичерпано, ElevenLabs віддає помилку, а застосунок сам переходить
на системний голос. Озвучка не зникає, лише спрощується.

Голос можна обрати свій: скопіювати `Voice ID` у кабінеті і покласти в
`ELEVENLABS_VOICE_ID`. Якщо не задавати — воркер візьме перший доступний.

### Azure — запасний варіант

Дає 500 000 символів на місяць замість 10 000, але вимагає картку і часто
блокує реєстрацію.

1. **portal.azure.com** → Create a resource → **Speech** → рівень **F0**
2. Ресурс → **Keys and Endpoint** → `KEY 1` і `Location/Region`
3. У воркері: `AZURE_SPEECH_KEY` і `AZURE_SPEECH_REGION`

Якщо задані обидва ключі, використовується ElevenLabs.

Поки ключа немає, `/tts` чесно повертає 503, і застосунок сам переходить на
системний голос («Леся» на macOS/iOS). Нічого не ламається — просто звучить
простіше.

## Що змінилось 25.09.2026

| | Було | Стало |
|---|---|---|
| Системна підказка агента | склеювалась у «[object Object],[object Object]» | доходить як є: персона, правила, дата |
| Хто може кликати | будь-хто (`*`) | лише свої сторінки (Origin) |
| Opus | дозволений усім | лише з `ALLOW_OPUS=1` |
| Стеля відповіді | до 64000 зі стрімом | 8192 |
| Частота | без обмежень | 30 на хвилину з IP |
| Вхід | не перевірявся | за бажання — сесія Supabase |
| Невідома адреса (`/translate`) | ішла в модель і падала з 400 | чесне 404 |
| Haiku з датою в назві | мовчки ставав дорожчим Sonnet | лишається Haiku |

**Підказка агента — головне.** Агент шле системну підказку двома блоками:
незмінна частина і свіжа (сьогоднішня дата, контекст). Воркер робив із них
рядок, і модель отримувала «[object Object],[object Object]» замість персони,
правил безпеки й дати. Помилки при цьому не було, тож ніхто не бачив, а модель
вгадувала дату й мову.

## Що змінилось 30.08.2026

| | Було | Стало |
|---|---|---|
| Стеля відповіді | 4096 завжди | до 64000 зі стрімом |
| Думання моделі | немає | адаптивне, де модель це вміє |
| Кешування підказки | немає | системна підказка + інструменти |
| Модель Sonnet | 4.6 ($3/$15) | 5 ($2/$10) — новіша й дешевша |
| Помилки | голе «HTTP 400» | текст від Anthropic |
| Таймаут | немає | 180 с, потім зрозуміла відповідь |
| Захист адреси | немає | `FLOW_SECRET` (необовʼязково; 25.09 замінено «Замком») |
| Голос | реверс Edge (не працює з Cloudflare) | офіційний Azure Speech |

### Чому саме ці зміни

**Стеля 4096** обривала довгі плани й розбори на півслові. Тепер велика стеля
дозволена лише зі стрімом — без нього запит не встиг би за таймаут.

**Думання** — головне. Модель сама вирішує, скільки міркувати. Це різниця між
«склав список» і «побачив закономірність». Безпечно, бо застосунок повертає
блоки думання назад у розмову (`conv.push` з усім `content`).

**Кешування.** Системна підказка й описи 14 інструментів однакові з ходу в хід,
але летіли в модель щоразу заново. В агентному циклі буває 3–5 ходів — тепер
повторне читання коштує близько десятої частини.

**Sonnet 4.6 → 5.** Підміна відбувається у воркері, застосунок правити не треба.
Новіша модель, і водночас дешевша.

## Моделі

Застосунок обирає модель сам (`aiPickModel`): простий запит — Haiku,
складний («розплануй», «проаналізуй», довгий текст) — Sonnet.

| Модель | Вхід / вихід за млн | Думає |
|---|---|---|
| `claude-haiku-4-5` | $1 / $5 | ні |
| `claude-sonnet-5` | $2 / $10 | так |
| `claude-opus-5` | $5 / $25 | так |

`claude-opus-5` закритий, доки у воркері не задано `ALLOW_OPUS=1`. Застосунок
його поки не просить. Якщо захочеш найрозумнішу модель на важких задачах,
потрібні і змінна, і правка в `aiPickModel` (`src/scripts/core/12-ai-agent.js`),
скажи.

## Перевірити, що працює

**Без Cloudflare, на Mac** (нічого не коштує, в Anthropic нічого не йде):

```bash
node --check worker/flow-ai-worker.js
node worker/test-worker.mjs
```

Друга команда підміняє мережу й перевіряє замок і підказку. Останній рядок
має бути «✅ Воркер: усі перевірки пройдено».

**Живий воркер після Deploy** (підстав свою адресу):

```bash
# свій сайт — має прийти JSON з відповіддю «працює»
curl -s -X POST <адреса-воркера> \
  -H 'origin: https://frequency-os.github.io' \
  -H 'content-type: application/json' \
  -d '{"model":"claude-haiku-4-5","max_tokens":64,"messages":[{"role":"user","content":"скажи: працює"}]}'

# чужий сайт — має прийти 403
curl -s -o /dev/null -w '%{http_code}\n' -X POST <адреса-воркера> \
  -H 'origin: https://evil.example' -H 'content-type: application/json' -d '{}'

# Opus без ALLOW_OPUS — має прийти 403 (у модель запит не йде)
curl -s -o /dev/null -w '%{http_code}\n' -X POST <адреса-воркера> \
  -H 'origin: https://frequency-os.github.io' -H 'content-type: application/json' \
  -d '{"model":"claude-opus-5","max_tokens":16,"messages":[{"role":"user","content":"hi"}]}'
```

Потім відкрий застосунок і спитай агента «яка сьогодні дата?». Правильна дата
у відповіді означає, що підказка дійшла.

Якщо помилка — у відповіді буде причина, а не просто код.
