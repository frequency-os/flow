# Словник Ярослава: програмування на прикладі Frequency

Тут живуть слова, які звучать у роботі над Frequency. Кожне — українською, з англійським
оригіналом і прикладом з нашого проєкту. Словник доповнює Claude, щойно вживає нове слово.

Як читати: **Слово** (англ. *word*, як вимовляти) — що це простими словами. *У Frequency:* приклад.

---

## 1. Код і як він виконується

- **Код** (*code*) — текст-інструкція для компʼютера. *У Frequency:* усе в папці `src/`.
- **Файл / папка** (*file / folder*) — код розкладено по файлах, як розділи книжки. *У Frequency:* `src/scripts/core/46-wallet.js` — усе про Гаманець.
- **JavaScript, JS** (*джаваскрипт*) — мова, якою написана логіка Frequency: що робить кнопка, як рахуються гроші.
- **HTML** (*ейч-ті-ем-ел*) — розмітка: з яких блоків складається екран (кнопка, заголовок, поле).
- **CSS** (*сі-ес-ес*) — оформлення: кольори, відступи, шрифти. *У Frequency:* папка `src/styles/`.
- **Функція** (*function*) — іменований шматок коду, який щось робить, коли його «викликають». *У Frequency:* `walletBalance()` рахує баланс.
- **Змінна** (*variable*) — коробочка з назвою, де лежить значення. *У Frequency:* `finOps` — список усіх операцій.
- **Масив** (*array*) — список значень по порядку. *У Frequency:* `envelopes` — масив конвертів.
- **Обʼєкт** (*object*) — набір полів «назва → значення». *У Frequency:* операція `{type:'out', amount:300, label:'Кафе'}`.
- **Подія / обробник** (*event / handler*) — «коли натиснули кнопку — зробити це». *У Frequency:* `onclick` на кнопці «Записати».
- **Рендер** (*render*) — намалювати екран з даних. *У Frequency:* `renderFinance()` перемальовує Гаманець.

## 2. Дані і сховище

- **Дані** (*data*) — те, що вводиш ти: операції, місії, нотатки. Код — правила, дані — твоє життя в програмі.
- **Сховище** (*storage*) — де дані лежать між запусками. *У Frequency:* памʼять телефона + хмара.
- **localStorage** (*локал-сторедж*) — маленька памʼять браузера на цьому пристрої.
- **Хмара** (*cloud*) — сервер в інтернеті (у нас Supabase), де лежить копія даних для всіх пристроїв.
- **Ключ** (*key*) — назва «шухляди» в сховищі. *У Frequency:* `fin_ops` — шухляда з операціями.
- **Синхронізація, синк** (*sync*) — звірка даних між телефоном, Mac і хмарою.
- **Бекап** (*backup*) — запасна копія даних у файлі. *У Frequency:* Ще → Дані → «Експорт у файл».
- **Міграція** (*migration*) — разова переробка старих даних під новий формат. Найризиковіше місце: помилка = зіпсовані дані.
- **Єдине джерело правди** (*single source of truth*) — кожна річ зберігається в одному місці, а решта лише показує її. *У Frequency:* віджет «Звичка» в папці не має своїх позначок — він читає трекер місії, тому вони ніколи не розходяться.

## 3. Git — історія коду

- **Git** (*гіт*) — «машина часу» для коду: памʼятає кожну зміну.
- **Коміт** (*commit*) — збережена точка в історії з описом «що змінено». Можна повернутись до будь-якої.
- **Гілка** (*branch*) — паралельна версія коду. *У Frequency:* нічна робота жила в гілці `night/2026-10-10-money`, поки ти не сказав «зливай».
- **main** (*мейн*) — головна гілка, з неї збирається сайт.
- **Злиття** (*merge*) — перенести зміни з однієї гілки в іншу.
- **Робоча копія** (*worktree*) — окрема папка з іншою гілкою, щоб дві роботи не заважали одна одній.
- **Дифф** (*diff*) — список «що було → що стало» між двома версіями.
- **Незакомічені зміни** (*uncommitted changes*) — правки, які ще не збережено в історію.
- **Стек stash** (*stash stack*) — stash-шухляди лежать стосом: `git stash pop` бере верхню, навіть якщо вона не твоя. Тому перед `pop` дивляться `git stash list`. *У Frequency:* 10.10 `pop` ледь не виклав відкладений 3D-світ замість файлів героїв.
- **Stash** (*стеш*) — тимчасово відкласти незакомічені правки «в шухляду», а потім повернути.
- **Ігнорований файл** (*ignored file*, «іґно́рд файл») — файл чи папка, яких git навмисно «не бачить»: не пропонує закомітити й не відправляє в репо. Список таких — у `.gitignore` (спільний) або `.git/info/exclude` (лише на цьому Mac). *У Frequency:* `референси/` і `баги-з-телефона/` — git їх не бачить, тож вони не потрапляють у публічне репо.

## 4. Збірка, перевірка, публікація

- **Збірка** (*build*) — склеїти всі файли з `src/` в один готовий сайт у `dist/`. Команда `npm run build`.
- **npm** (*ен-пі-ем*) — інструмент, що запускає наші команди: `npm run check`, `npm run deploy`.
- **Перевірка** (*check*) — `npm run check`: чи код без синтаксичних помилок, чи збирається, чи все на місці.
- **Димовий тест** (*smoke test*) — швидко відкрити зібране і переконатися, що «не димить»: екрани відкриваються, помилок нема.
- **Деплой / публікація** (*deploy*) — викласти нову версію на сайт, звідки її бере телефон.
- **Прев'ю** (*preview*) — локальний перегляд сайту в браузері до публікації.
- **Консоль** (*console*) — «чорний ящик» браузера, куди пишуться помилки.

## 5. Безпека і надійність

- **Рецензія** (*review*) — інший агент читає зміни і шукає помилки до коміту. У нас два: дані (*data-safety*) і безпека (*security*).
- **XSS** (*ікс-ес-ес*, cross-site scripting) — коли чужий текст (наприклад, назва з посилання) потрапляє в сторінку як код і виконується. Захист — екранування.
- **Екранування** (*escaping*) — перетворити небезпечні символи `<`, `>`, `"` на безпечний текст. *У Frequency:* функція `esc()`.
- **Автозапис** (*auto-write*) — коли програма сама щось записує без твого тапу. Головне джерело втрат даних, тому в нас правило: гроші лише пропонуються, записуєш ти.
- **Умова-охоронець** (*guard clause*, «ґард клоз») — перевірка на початку функції, що одразу виходить, коли робити нічого не треба. *У Frequency:* `wlStartHTML` не малює картку «З чого почнемо?», доки хмара не відповіла, — щоб «ще вантажиться» не сплутати з «порожньо».
- **Тестові дані** (*test data*) — вигадані записи для перевірки, які після перевірки прибирають. *У Frequency:* рядок Плану «Зарплата» на 20 000, створений у прев'ю, щоб побачити, що автозарплата його закриває.
- **Надгробок** (*tombstone*, «ту́мстоун») — запис «це видалено», який лишають замість стертого, щоб стара копія з іншого пристрою його не «воскресила». *У Frequency:* ключ `fin_tomb` — id операцій і конвертів, стертих кнопкою «Почати фінанси з нуля».
- **Гонка двох пристроїв** (*race condition*) — два пристрої пишуть одне й те саме майже одночасно, і новіший тихо перекриває старіший.

## 6. Інтерфейс

- **Інтерфейс, UI** (*user interface*) — усе, що видно і на що можна натиснути.
- **Шторка** (*sheet*) — панель, що виїжджає знизу (наприклад «− Витрата»).
- **Порожній стан** (*empty state*, «е́мпті стейт») — що показує екран, коли даних ще нема. Добрий порожній стан підказує перший крок. *У Frequency:* картка «З чого почнемо?» в порожньому Гаманці.
- **Майстер** (*wizard*, «ві́зард») — шторка, що веде крок за кроком і сама відкриває наступний крок. *У Frequency:* «Новий старт» у Гаманці — залишок → конверти → дохід → План.
- **Колбек** (*callback*, «ко́лбек») — функція, яку передають іншій функції зі словами «виклич мене, коли закінчиш». *У Frequency:* `wlEnvStarter(done)` — після створення конвертів викликає `done`, і майстер переходить до розкладання грошей.
- **Абсолютне позиціювання** (*absolute positioning*, «е́бсолют позі́шенінг») — поставити елемент у точні координати всередині «рамки», а не в загальний потік. *У Frequency:* справа о 16:00 у сітці дня стоїть на `top = (16 − 7) × 52 px`, а її висота = тривалість × 52 px.
- **Віджет / плитка** (*widget / tile*) — маленьке «вікно» з даними на екрані. *У Frequency:* плитки «Гроші місії», «⏱ Робота».
- **Адаптивність** (*responsive*) — однаково добре на телефоні 375 px і на ноуті.
- **PWA** (*пі-дабл-ю-ей*, Progressive Web App) — сайт, який ставиться на iPhone як застосунок. Так зараз живе Frequency на телефоні.
- **Посилання з параметрами** (*URL parameters*) — `…/flow/?add=out&amount=230`: частина після `?` передає дані в програму. *У Frequency:* так Apple Pay відкриває шторку витрати.
- **Шар** (*layer*, «ле́єр») — прозора картинка, яку кладуть поверх іншої. *У Frequency:* одяг героя — шар поверх кадру з емоцією, тому будь-яке худі лягає на будь-який настрій.
- **Кадр / спрайт** (*frame / sprite*) — одна з набору готових картинок того самого персонажа. *У Frequency:* 9 кадрів Міи — по одному на кожну емоцію.
- **Макет** (*mockup*, «мо́кап») — картинка майбутнього екрана, зроблена до коду: дешево порівняти варіанти й вибрати. *У Frequency:* три макети першого екрана з Higgsfield, з яких обрано «Стартовий набір».
- **Онбординг** (*onboarding*, «онбо́рдинг») — перші хвилини нової людини в програмі: що вона бачить і який перший крок робить. *У Frequency:* «Стартовий набір» на порожньому Огляді.
- **Ліниве завантаження** (*lazy loading*, «ле́йзі ло́удінг») — важкий файл тягнеться лише тоді, коли справді потрібен. *У Frequency:* фото прикладу (`starter-assets.js`) вантажаться лише новим людям з порожнім акаунтом.
