# Як ставити задачу Claude

Добра задача економить півгодини уточнень. Заповни шаблон і встав у чат.
Порожні рядки можна лишити — Claude сам про них спитає (по одному питанню).

## Шаблон

```text
Задача: <що зробити одним реченням>

Навіщо: <яку проблему це знімає для мене чи людини в застосунку>

Тип задачі: розвідка / точкова правка / нова система
  (не знаєш — напиши «не знаю», Claude визначить за правилом 1 CLAUDE.md)

Як я зрозумію, що вийшло: <що саме побачу на телефоні, 375×812;
  який екран, яку кнопку натисну, що має статися>

Обмеження:
  - Не чіпати: <файли, екрани, дані>
  - Дані: <чи можна змінювати формат збережених даних — так / ні>
  - Інша сесія зараз робить: <файли або «нічого»>

Деплой: так, після перевірки / ні, лише гілка
```

## Що Claude робить у відповідь

Залежно від типу (правило 1 CLAUDE.md):

| Тип | Відповідь Claude до коду |
|---|---|
| **Розвідка** — чи це взагалі можливо, код на викид | 2–3 речення: що перевіряє і як. Чекає кивка |
| **Точкова правка** — зміна в наявній системі з `CODEMAP.md` | Уточнення по одному → короткий опис → чекає «так» |
| **Нова система** — новий файл у `src/scripts/core/`, зміна структури | Питання → 2–3 варіанти з чесними мінусами → опис по пунктах → чекає «так» |

Потім — правка, `npm run check`, перевірка в браузері на 375×812 і знімок
екрана. «Готово» — лише з показаним виводом перевірки.

## Приклад 1. Точкова правка

```text
Задача: на картці Огляду показувати тиждень у відсотках, а місяць — тихим рядком.
Навіщо: відсоток місяця на початку місяця завжди близький до нуля і демотивує.
Тип задачі: точкова правка.
Як я зрозумію, що вийшло: відкриваю Огляд на iPhone — велика цифра це тиждень,
  під нею дрібно «місяць: N%», усе вирівняно по лівому краю, в обох темах.
Обмеження:
  - Не чіпати: логіку підрахунку цілей, тільки показ.
  - Дані: формат не міняти.
  - Інша сесія зараз робить: нічого.
Деплой: ні, лише гілка.
```

## Приклад 2. Нова система

```text
Задача: чати окремо від папок — вкладки «Папки · Чати», «Вхідні» стають чатом.
Навіщо: зараз розмова з агентом і документи лежать упереміш, важко знайти.
Тип задачі: нова система (новий файл у src/scripts/core/).
Як я зрозумію, що вийшло: на екрані папок дві вкладки; у «Чати» — список
  чатів, «Вхідні» серед них; мої старі записи з «Вхідних» на місці.
Обмеження:
  - Не чіпати: вміст наявних папок.
  - Дані: так, але лише копією, старий ключ лишається (дивись workflows/mihratsiia-danykh.md).
  - Інша сесія зараз робить: 20-depth.css — не чіпати.
Деплой: так, після перевірки і після мого бекапу на телефоні.
```

Тут Claude спершу покаже 2–3 варіанти (наприклад, «чат — окрема сутність»
проти «чат — вид папки») з мінусами кожного і чекатиме вибору.

## Приклад 3. Розвідка

```text
Задача: з'ясувати, чи можна записати голосове прямо з нижньої панелі
  на iPhone у режимі «На екран Домівка».
Навіщо: хочу швидкі голосові нотатки без відкривання папки.
Тип задачі: розвідка, код на викид.
Як я зрозумію, що вийшло: відповідь «так/ні/так, але…» з доказом —
  знімок з емуляції 375×812 і що каже консоль про дозвіл мікрофона.
Обмеження:
  - Не чіпати: src/ у main — усе лише в scratchpad.
  - Дані: не змінювати.
Деплой: ні.
```

## Поради

- **Одна задача — один чат.** Кілька тем в одному чаті змішують коміти.
- **Голосом?** Claude перекаже задачу одним реченням і спитає, чи правильно.
- **«Просто» — це короткий задум, а не його відсутність.**
- **Бачиш у відповіді «має працювати»** — попроси показати вивід перевірки.
