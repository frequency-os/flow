# Точкова правка

> Для зміни в наявній системі з `CODEMAP.md`: інший текст, колір, відступ,
> поведінка однієї кнопки. Встав і допиши задачу вгорі.

---

Задача: <…>
Як я зрозумію, що вийшло: <що побачу на телефоні>

Працюй за процесом «точкова правка» Frequency:

1. **Знайди місце.** `grep -n '<слово>' CODEMAP.md`, потім `grep -rn` у
   `src/` за текстом з екрана. Прочитай лише потрібні рядки (`sed -n`).
   Перевір, чи функцію не перехоплено десь `window.<ім'я> = …`.
2. **Уточни** — по одному питанню, якщо щось неоднозначне.
3. **Короткий опис у чаті**: файл:рядок, що саме зміниш, як доведеш.
   **Чекай «так».**
4. **Якщо це баг** — спершу відтвори симптом (прев'ю 375×812, node-скрипт,
   `TZ=…` для дат) і покажи його **до** правки.
5. **Правка** — мінімальна, у стилі сусіднього коду.
   - CSS: не додавай `!important`; правило для нових тем — з префіксом
     `html.t-flat`, ефекти глибини — у `20-depth.css`.
   - Дати — лише `ymdLocal()`.
   - Автозаписи папок — лише `saveFolders({auto:true})`.
6. **Доказ:**
   ```bash
   npm run map && npm run check     # «Все гаразд.»
   ```
   Видима зміна → `/frequency-verify` (375×812, консоль, знімок).
   Баг → покажи, що симптому **після** правки нема.
7. **Коміт** лише своїх файлів: `git commit -- <шляхи> CODEMAP.md`.
