# Нічна зміна

> Кілька незалежних виправлень паралельно, поки Ярослав спить. Кожне —
> у своїй гілці й своєму worktree. Уранці Ярослав переглядає і сам вирішує,
> що зливати.

---

## Перед стартом (Ярослав каже «так» на список)

1. **Список задач** — кожна з метою, файлами і «як доведу» (шаблон
   [`../00-yak-stavyty-zadachu.md`](../00-yak-stavyty-zadachu.md)).
2. **Незалежність.** Дві задачі, що правлять той самий файл, — в одну гілку
   або послідовно, не паралельно.
3. **Нічого необоротного вночі:** жодних міграцій на справжніх даних,
   деплою, `git push`, злиття в main, оновлення `src/vendor/`.

## Правила для кожного агента

- **Не більше 3 агентів одночасно.** Решта — у черзі.
- **Свій worktree** у `.claude/worktrees/<назва>` (він у `.gitignore`) і
  **своя гілка** від main: `git checkout -B night/<тема> main`.
- **Основне дерево** `/Users/yarosla/frequency` — лише читати.
- **Свій `dist/`**: збирати й перевіряти в корені свого worktree. Прев'ю —
  на своєму порту (`autoPort` у `.claude/launch.json`).
- **Дані користувача не чіпати:** ні `snapshot.sh`/`restore.sh`, ні хмари,
  ні `npm run dev` / `npm start` (вони працюють зі справжніми даними).
- **Відтворити симптом до правки** і показати, що після нього нема.
- **Доказ у корені worktree:**
  ```bash
  npm run map
  npm run check         # «Все гаразд.»
  npm run smoke         # якщо скрипт уже є (гілка night/check-gate)
  ```
- **Коміт** лише своїх файлів: `git commit -- <шляхи> CODEMAP.md`.
  Українською: що й чому + як перевірено.
- Не встиг — закоміть **перевірену** частину і чесно напиши «частково».

## Звіт на ранок

Для кожної гілки, простими словами:

| Гілка | Що зроблено | Було → стало | Доказ (вивід check) | Ризики | Що треба від Ярослава |
|---|---|---|---|---|---|

## Уранці (Ярослав)

1. Прочитати звіт, відкрити гілки з «готово».
2. Для видимих змін — `/frequency-verify` на гілці.
3. Злити обране в main, потім [`publikatsiia.md`](publikatsiia.md).
4. Прибрати worktree: `git worktree remove .claude/worktrees/<назва>`.
