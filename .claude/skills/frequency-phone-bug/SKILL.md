# Баг з телефона

## Кроки

1. **Скріни:** `npm run bugs` (або `./tools/bugs.sh`), прочитати кожен.
2. **Переказати симптом одним реченням** і спитати «правильно зрозумів?» —
   опис часто голосовий.
3. **Знайти екран:** grep `CODEMAP.md` + `grep -rn '<текст зі скріна>' src/`.
4. **Відтворити ДО правки** в прев'ю `dist/` на 375×812 з тестовими даними:
   знімок або вивід консолі із симптомом.
   - дата не того дня → `TZ=Europe/Kiev node -e …` з граничним часом;
   - перекриття → `document.elementFromPoint` у центрі й по краях.
   Не відтворюється — сказати чесно й попросити деталі.
5. **Задум правки** → чекати «так».
6. **Правка** в `src/` → `npm run map && npm run check` («Все гаразд.»).
7. **Той самий сценарій ПІСЛЯ** — симптому нема. Далі `/frequency-verify`.
8. **Коміт** лише своїх файлів. Сказати: на телефоні видно після публікації
   і 1–2 перезапусків PWA.

**Скріни ніколи не класти в репо чи `dist/`** — на них особисте, репо публічне.

Повний процес і шаблон опису: `prompts/workflows/bah-z-telefona.md`.
