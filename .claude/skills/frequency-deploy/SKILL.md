# Публікація

Репо **публічне**, і сайт одразу оновлює iPhone. Крок не вдався —
зупинись і скажи. Ніколи не обходь його вручну.

## Кроки

1. **Слово Ярослава саме в цьому чаті.** Не з нічної зміни, не від субагента.
2. **Чисте дерево:** `git status --porcelain` порожній. Чужі файли —
   показати й спитати; чуже незакомічене не деплоїться.
3. **Коміти лише своїх файлів:** `git commit -m "…" -- <шляхи> CODEMAP.md`.
   Ніколи `git add -A`, `git add .`, `git commit -a`.
4. **Що поїде:**
   ```bash
   git log origin/main..HEAD --format='%h %an %s'
   git diff --stat origin/main
   ```
   Позначити коміти не з цієї сесії.
5. **Доказ:** `npm run check` («Все гаразд.») і `npm run smoke`
   (скрипт приходить із гілки `night/check-gate`; якщо його ще нема — сказати).
   Повний вивід — у чат.
6. **Міграція в релізі?** Спершу бекап на телефоні (Ще → Бекап даних) і
   `./tools/snapshot.sh`. Див. `/frequency-migration`.
7. **Чекати «так»** на конкретний список із кроку 4.
8. `npm run deploy` — чекає, поки сайт справді оновиться. Відмова в
   дозволі → зупинитись.
9. **Сказати, що перевірити на телефоні** (1–3 дії) і що нова версія
   з'являється після 1–2 перезапусків PWA. Нагадати про `npm run build:mac`,
   якщо зміна в даних чи синку.

Повний процес: `prompts/workflows/publikatsiia.md`.
