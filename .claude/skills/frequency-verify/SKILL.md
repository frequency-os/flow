# Перевірка зміни на 375×812

Доводить, що зміна працює **в програмі**, а не лише збирається.
Для змін, яких не видно на екрані (tools/, документація), вистачає `npm run check`.

## Кроки

1. **Збірка й доказ:**
   ```bash
   npm run map && npm run check     # має закінчитись «Все гаразд.»
   ```
   Інакше — зупинись і покажи вивід.
2. **Прев'ю:** `preview_start` з конфігом `frequency` (`.claude/launch.json`,
   роздає `dist/` на порту 4173, `autoPort`). У worktree — свій `dist/`.
3. **Розмір:** `resize_window` → `mobile` (375×812), перезавантажити сторінку.
4. **Дані:** лише тестові. Ніяких особистих даних, скрінів із телефона чи
   макетів у `dist/` — репо публічне.
5. **Клік саме по зміненому** — по-справжньому (`computer` / `find` + `ref`).
6. **Консоль:** `read_console_messages` з `onlyErrors`. Помилки = провал.
   Попередження гостьового режиму («saveFolders пропущено…») — окремим
   списком, щоб не маскували нові.
7. **Перекриття кнопки:** у `javascript_tool` для кожної зміненої кнопки —
   `document.elementFromPoint` у центрі й по 4 краях має повертати саму кнопку
   (або її нащадка), а не котика-напарника чи шторку.
8. **Нижня панель:** прокрутити донизу; `getBoundingClientRect().bottom`
   останнього блоку ≤ `top` у `.nav` (панель 77 px, `body` — `padding-bottom: 0`).
9. **Теми:** якщо зміна в CSS — повтори знімок у світлій і темній темі.
10. **Знімок екрана** — показати Ярославу.
11. **Прибрати:** `resize_window` → `desktop`; зупинити прев'ю.

## Звіт

Команда і повний підсумок `npm run check`, що натиснуто, консоль (N помилок),
результати `elementFromPoint`, знімок. Чесно — що **не** перевірено
(справжній телефон, вхід у Google, другий пристрій).
