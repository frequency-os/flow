# Новий екран

Це **нова система** за правилом 1: питання по одному → 2–3 варіанти з
мінусами → опис по пунктах → **«так»**.

## Кроки

1. **Файл JS** — наступний вільний номер (`37-…js`). Наявні не перенумеровувати.
2. **Імена** з префіксом модуля — усі файли core склеюються в один `<script>`.
3. **Розмітка** — `<section class="screen" id="scr-…">` у `src/index.html`;
   вхід зі звичайного UI і «назад» туди, звідки прийшли.
4. **CSS** — новий файл, підключений у `src/index.html`; не правити чужі.
   - Кольори — лише токени (`--bg`, `--bg-2`, `--card`, `--card-2`, `--line`,
     `--hair`, `--muted`, `--accent`).
   - Правила для нових тем — з `html.t-flat` (клас ставить `applyTheme()`,
     `05-spaces.js`; світла — ще `t-light`).
   - Тіні, підйом, матове скло — токени з `20-depth.css`.
   - Без нових `!important`.
5. **Телефон:** шапка з `env(safe-area-inset-top)`; останній блок не під
   `.nav` (77 px, `body` без `padding-bottom`); тап-зони ≥44×44; поля ≥16px.
6. **Ключі** — у `FLOW_KEYS`, через `window.storage`; автозаписи — `/frequency-migration`.
7. `npm run map && npm run check` → «Все гаразд.»
8. `/frequency-verify` у 4 станах: desk темна/світла, studio темна/світла.
9. **Коміт** лише своїх файлів + рядок у README «Карта систем».

Повний процес: `prompts/workflows/novyi-ekran.md`.
Рецензія: субагент `ui-verifier`.
