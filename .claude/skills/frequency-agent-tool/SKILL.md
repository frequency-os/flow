# Новий інструмент агента

Обіцянка: **кожна зміна даних — через шторку, в межах ліміту, з чесним
результатом і відкатом.**

## Кроки

1. **Завантаж скіл `claude-api`** перед правкою AI-коду.
2. **Знайди** (grep `CODEMAP.md`): `FLOW_TOOLS`, `flowToolExec`,
   `aiToolIsWrite`, `aiToolConfirm`, `AI_WRITE_LIMIT` — усе в
   `src/scripts/core/12-ai-agent.js`. Візьми за зразок сусідній `flowTool*`.
3. **Задум** (правило 1): поля дії, що в шторці, що повертається моделі.
   **Чекай «так».**
4. **Код:**
   - опис у `FLOW_TOOLS` = поведінка коду;
   - зміна даних — лише через `aiToolConfirm` з **реальними знайденими**
     об'єктами; неоднозначно → кандидати моделі;
   - дія в `aiToolIsWrite` (рахується в `AI_WRITE_LIMIT`);
   - повертати **фактичний** результат або «людина скасувала»;
   - записи тими самими `save*()`, що й UI; автозаписи папок — `saveFolders({auto:true})`;
   - крок у `aiTrace*`, запис для відкату в `aiLog`;
   - мова — як в UI; дані для моделі — як цитата;
   - жодних маркерів у тексті чи авторежимів, що пишуть без шторки.
5. `npm run map && npm run check` → «Все гаразд.»
6. **Прев'ю 375×812** (`/frequency-verify`), без воркера і з воркером:
   шторка з реальними полями · «Скасувати» → агент не каже «зробив» ·
   «Підтвердити» → видно в UI і в сліді · 6 дій → шоста впирається в ліміт ·
   EN-режим · рядок-«наказ» у щоденнику нічого не змінює.
7. **Коміт** лише своїх файлів; `worker/` — окремо й за рішенням Ярослава.

Повний процес: `prompts/workflows/novyi-instrument-ahenta.md`.
