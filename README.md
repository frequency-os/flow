# Frequency

Особиста «операційна система життя»: папки, дошки, фінанси, цілі, планер,
щоденник, читалка, AI-компаньйон, агенція.

---

## Головне правило

**Програму НЕ редагують у `dist/index.html`.**
Редагують файли в `src/` → потім запускають збірку → з'являється `dist/index.html`.

```
src/  (те, що ти правиш)  ──збірка──▶  dist/index.html  (те, що працює)
```

`dist/index.html` — це один великий файл, точно такий самий, як був раніше.
Саме його відкриває браузер, Telegram, iPhone і Android. Ніщо в поведінці
програми не змінилось — змінилось лише те, як код зберігається на диску.

---

## Як зібрати

Подвійний клік по **`build.command`** — і все.

Або в терміналі:

```bash
cd ~/frequency && python3 tools/build.py
```

## Як перевірити, що нічого не зламано

```bash
cd ~/frequency && ./tools/check.sh
```

Скрипт: (1) перевіряє синтаксис усіх JS-файлів справжнім движком JavaScript,
(2) збирає програму, (3) порівнює з еталоном `original/index11.html`.

## Що де лежить

| Тека | Що це |
|---|---|
| `src/index.html` | Каркас: вся HTML-розмітка + маркери `@@INC:...@@`, куди підставляються частини |
| `src/styles/` | Оформлення (CSS) |
| `src/styles/core/` | Основне оформлення, порізане на 15 тем |
| `src/scripts/` | Код (JS) |
| `src/scripts/core/` | Головний код, порізаний на 29 систем |
| `src/scripts/page-editor/` | Редактор сторінки (Notion-стиль) — 9 частин |
| `dist/index.html` | **Готова програма.** Створюється збіркою |
| `original/index11.html` | Недоторканий еталон «як було до розбору» |
| `tools/` | Скрипти збірки та перевірки |
| `CODEMAP.md` | Карта коду (де яка система живе) |

### Маркери в каркасі

У `src/index.html` замість коду стоять маркери:

* `@@INC:styles/04-diary.css@@` — підставити один файл
* `@@INCDIR:scripts/core@@` — підставити **всі** файли з теки, за абеткою

Тому в `core/` файли пронумеровані (`01-…`, `02-…`): **номер = порядок виконання**.
Порядок міняти не можна — код розрахований на нього.

## Що далі (не зроблено)

Щоб програма стала застосунком на Mac / Windows / Android / iPhone:

1. Локально покласти шрифти Google Fonts (зараз тягнуться з інтернету — в офлайні не буде).
2. Прибрати залежність від `telegram.org/js/telegram-web-app.js` у нетелеграмних збірках.
3. Встановити Node.js, обгорнути `dist/` через Capacitor (iPhone/Android) і Tauri або Electron (Mac/Windows).
